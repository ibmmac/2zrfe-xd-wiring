# 2ZR-FE / Scion xD harness wiring

Shop notes for a **2ZR-FE** + **U341E** from a **2009 Scion xD** in a **2010 Yaris 5-door hatch**.

| | VIN | What |
|---|---|---|
| Chassis | `JTDKT4K35A5318649` | 2010 Yaris 5-door, built 5MT, VSC, no OFF button — keep **A30** |
| Donor | `JTKKU10409J041220` | 2009 xD **2ZR-FE + U341E** + Engine/ECT ECU |

**Start here for speed:** [docs/SPEED_CAN.md](docs/SPEED_CAN.md)

The U341E has no VSS. Cluster speed is **Yaris A30 CAN** (pins 25/14), not A30 pin 4.
